\chapter{Continuous Probability Distributions: Uniform \& Exponential}

While discrete random variables model integers and counts, applied data science and statistical computing frequently measure physical phenomena that are infinitely divisible: response latency in milliseconds, vehicle speeds, financial asset prices, and inter-arrival durations. For continuous variables, probability can no longer be concentrated in point masses ($\P(X = c) = 0$ for every individual real coordinate $c$). Instead, probability mass transitions into the continuous calculus of \textbf{Probability Density Functions (PDFs)} and integrated areas. In this final foundational chapter, we master \textbf{Continuous Random Variables and PDFs}, \textbf{the Fundamental Theorem of Continuous CDFs}, the \textbf{Continuous Uniform Distribution}, the \textbf{Exponential Distribution}, its unique \textbf{Memoryless Property}, and the crucial cognitive traps: \textbf{why densities can exceed 1}, \textbf{zero point probability vs. impossibility}, and \textbf{the boundary invariance of continuous intervals}.

\section{The Probability Density Function (PDF)}

For a continuous random variable $X$, the sample space contains an uncountably infinite number of points. Assigning any finite positive probability $p > 0$ to individual real numbers would cause the sum of probabilities across any interval to explode to infinity, violating Kolmogorov's second axiom ($\P(\Omega) = 1$).

\begin{definitionbox}{Probability Density Function (PDF)}
\index{Probability Density Function (PDF)}
A continuous random variable $X$ is characterized by a non-negative function $f_X \colon \mathbb{R} \to [0, \infty)$ called the \textbf{Probability Density Function (PDF)}, such that for any measurable interval $[a, b]$:
$$\P(a \le X \le b) = \int_a^b f_X(x) \, dx$$
\begin{itemize}
    \item \textbf{Kolmogorov Validity Criteria:}
    \begin{enumerate}
        \item \textbf{Non-Negativity:} $f_X(x) \ge 0$ for all $x \in \mathbb{R}$.
        \item \textbf{Total Area Normalization:}
        $$\int_{-\infty}^\infty f_X(x) \, dx = 1.00$$
    \end{enumerate}
    \item \textbf{Single-Point Probability is Strictly Zero:} For any individual constant $c \in \mathbb{R}$:
    $$\P(X = c) = \int_c^c f_X(x) \, dx = 0$$
    \item \textbf{Boundary Indifference:} Because single points carry zero probability mass, inequality boundaries make zero difference in continuous probability:
    $$\P(a < X < b) = \P(a \le X < b) = \P(a < X \le b) = \P(a \le X \le b)$$
\end{itemize}
\end{definitionbox}

\begin{theorembox}{The Continuous Cumulative Distribution Function (CDF)}
\index{Continuous CDF}
The Cumulative Distribution Function of a continuous random variable $X$ is defined for all $x \in \mathbb{R}$ by:
$$F_X(x) = \P(X \le x) = \int_{-\infty}^x f_X(t) \, dt$$
By the \textbf{Fundamental Theorem of Calculus}, wherever $f_X(x)$ is continuous:
$$f_X(x) = \frac{d}{dx} F_X(x) = F_X'(x)$$
The PDF is the exact derivative (slope) of the CDF!
\end{theorembox}

\section{The Continuous Uniform Distribution}

The continuous analog of the fair die is the Continuous Uniform distribution, where probability is distributed with constant density across an interval.

\begin{definitionbox}{Continuous Uniform Distribution}
\index{Uniform Distribution}
A continuous random variable $X$ follows a \textbf{Uniform Distribution} on $[a, b]$, denoted $X \sim \text{Uniform}(a, b)$ with $a < b$, if its PDF is constant:
$$f_X(x) = \begin{cases}
\frac{1}{b - a}, & a \le x \le b \\[4pt]
0, & \text{otherwise}
\end{cases}$$
\begin{itemize}
    \item \textbf{Cumulative Distribution Function (CDF):}
    $$F_X(x) = \begin{cases}
    0, & x < a \\[4pt]
    \frac{x - a}{b - a}, & a \le x \le b \\[4pt]
    1, & x > b
    \end{cases}$$
    \item \textbf{Expected Value (Midpoint):} $\E[X] = \int_a^b \frac{x}{b-a} dx = \frac{a + b}{2}$.
    \item \textbf{Theoretical Variance:}
    $$\Var(X) = \E[X^2] - (\E[X])^2 = \frac{b^2 + ab + a^2}{3} - \frac{(a + b)^2}{4} = \mathbf{\frac{(b - a)^2}{12}}$$
\end{itemize}
\end{definitionbox}

\section{The Exponential Distribution}

While the Poisson process counts \emph{how many} rare events occur per unit time, the \index{Exponential Distribution}\textbf{Exponential Distribution} measures the continuous waiting time or duration between those successive arrivals.

\begin{definitionbox}{The Exponential Distribution}
\index{Exponential Distribution}
A continuous random variable $X$ has an \textbf{Exponential Distribution} with rate parameter $\lambda > 0$, denoted $X \sim \text{Exp}(\lambda)$, if its support is $[0, \infty)$ and its PDF is:
$$f_X(x) = \begin{cases}
\lambda e^{-\lambda x}, & x \ge 0 \\
0, & x < 0
\end{cases}$$
\begin{itemize}
    \item \textbf{Cumulative Distribution Function (CDF):}
    $$F_X(x) = \int_0^x \lambda e^{-\lambda t} \, dt = \left[-e^{-\lambda t}\right]_0^x = \mathbf{1 - e^{-\lambda x}} \quad (x \ge 0)$$
    \item \textbf{Survival Function:} $\P(X > x) = 1 - F_X(x) = \mathbf{e^{-\lambda x}}$.
    \item \textbf{Moments via Integration by Parts:}
    $$\E[X] = \mathbf{\frac{1}{\lambda}}, \qquad \Var(X) = \mathbf{\frac{1}{\lambda^2}}, \qquad \SD(X) = \frac{1}{\lambda}$$
\end{itemize}
\end{definitionbox}

\begin{theorembox}{The Memoryless Property}
\index{Memoryless Property}
The Exponential distribution possesses a unique mathematical property among all continuous distributions: it is completely \textbf{Memoryless}:
$$\P(X > s + t \mid X > s) = \P(X > t) \quad \text{for all } s, t \ge 0$$
\textit{Proof:} Using the definition of conditional probability and the survival function:
$$\P(X > s + t \mid X > s) = \frac{\P(X > s + t \cap X > s)}{\P(X > s)} = \frac{\P(X > s + t)}{\P(X > s)} = \frac{e^{-\lambda(s + t)}}{e^{-\lambda s}} = \frac{e^{-\lambda s} e^{-\lambda t}}{e^{-\lambda s}} = \mathbf{e^{-\lambda t}} = \P(X > t)$$
\textbf{Physical Meaning:} Given that a server has already run without failure for $s = 100$ hours, the probability that it survives an additional $t = 50$ hours is identical to the probability that a brand-new server survives $50$ hours. The component does not age or wear out!
\end{theorembox}

\section{Cognitive Traps in Continuous Distributions}

\begin{trapbox}{Trap 1: Density $f(x)$ Can Legitimately Exceed 1.0!}
Students conditioned on discrete PMFs ($p(x) \le 1$) frequently panic upon seeing $f(x) > 1$.
\begin{itemize}
    \item Consider $X \sim \text{Uniform}(0, 0.2)$.
    \item The PDF is $f(x) = \frac{1}{0.2 - 0} = \mathbf{5.0}$ for $x \in [0, 0.2]$.
    \item A density of $5.0$ is completely mathematically valid! The total area under the curve is:
    $$\text{Area} = \text{width} \times \text{height} = 0.2 \times 5.0 = \mathbf{1.00}$$
    \item Density is probability \textbf{per unit length} ($[x]^{-1}$). Only integrated area is bounded by $1.0$.
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 2: Zero Point Probability Does NOT Imply Impossibility}
In continuous probability, $\P(X = c) = 0$ for every single real point $c$.
\begin{itemize}
    \item If you spin a precision wheel marked continuous $[0, 1)$, the probability of landing on exactly $0.41829\dots$ is zero.
    \item Yet, when you spin the wheel, \emph{some} real number with zero probability is guaranteed to be realized!
    \item An event with probability zero is not logically impossible; it is simply a set of Lebesgue measure zero.
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 3: Memoryless Queues vs. Real-World Mechanical Aging}
Assuming exponential lifetimes for physical machinery without validation is a major engineering trap.
\begin{itemize}
    \item The memoryless property implies that a 10-year-old car engine is just as likely to break down in the next hour as a brand-new engine straight out of the factory.
    \item For mechanical devices with friction, metal fatigue, and corrosion, the failure rate \textbf{increases} with age.
    \item \textbf{Data Science Rule:} Exponential distributions model purely memoryless processes (e.g. radioactive decay, packet arrivals). For physical systems that wear out with age, the \textbf{Weibull Distribution} is required!
\end{itemize}
\end{trapbox}

\section{Python Implementation: Continuous Distributions in SciPy}

\begin{lstlisting}[caption={Continuous Uniform and Exponential Distributions in Python}]
import numpy as np
import scipy.stats as stats

# 1. Continuous Uniform Distribution: U(0, 0.25) -> Demonstrating f(x) > 1
a, b = 0.0, 0.25
uniform_dist = stats.uniform(loc=a, scale=(b - a))

# Density evaluation: height is 1 / 0.25 = 4.0
density_val = uniform_dist.pdf(0.10)
print(f"Uniform PDF at x=0.10: f(x) = {density_val:.2f} (Density > 1.0!)")
print(f"Uniform Mean:           E[X] = {uniform_dist.mean():.4f}")
print(f"Uniform Variance:     Var(X) = {uniform_dist.var():.6f}")

# 2. Exponential Distribution: Exp(lambda = 0.5 per sec) -> scale = 1 / lambda = 2.0
lmbda = 0.5
exp_dist = stats.expon(scale=1.0 / lmbda)

print(f"\nExponential Mean wait time: E[X] = {exp_dist.mean():.2f} sec")
print(f"Exponential Std Dev:        SD(X)= {exp_dist.std():.2f} sec")

# 3. Memoryless Property Verification: P(X > 6 | X > 4) vs P(X > 2)
# Survival function is sf(x) = 1 - cdf(x)
p_greater_6 = exp_dist.sf(6.0)
p_greater_4 = exp_dist.sf(4.0)
p_conditional = p_greater_6 / p_greater_4
p_greater_2 = exp_dist.sf(2.0)

print(f"\nP(X > 6 | X > 4) = {p_conditional:.6f}")
print(f"P(X > 2)         = {p_greater_2:.6f} (Exact Memoryless Match!)")
\end{lstlisting}

\subsection*{Part A: Computational and Analytical Problems}

\begin{enumerate}
    \item \textbf{Validating a Continuous PDF:} A continuous random variable $X$ has proposed PDF:
    $$f_X(x) = \begin{cases}
    c \cdot x^2, & 0 \le x \le 3 \\
    0, & \text{otherwise}
    \end{cases}$$
    \begin{enumerate}
        \item Find the value of constant $c$ that normalizes the total area to $1.00$.
        \item Formulate the Cumulative Distribution Function $F_X(x)$ for all $x \in \mathbb{R}$.
        \item Compute $\P(1 \le X \le 2)$.
    \end{enumerate}

    \item \textbf{Uniform Waiting Time at Rapid Transit:} A subway train arrives at an automated platform uniformly between $0$ and $8$ minutes after a passenger enters the station ($X \sim \text{Uniform}(0, 8)$).
    \begin{enumerate}
        \item Write the mathematical PDF $f_X(x)$ and specify its height.
        \item Compute the expected waiting time $\E[X]$ and variance $\Var(X)$.
        \item Compute the probability that the passenger waits strictly between $3$ and $7$ minutes.
    \end{enumerate}

    \item \textbf{Exponential Cloud Server Latency:} An API endpoint response time $T$ follows an Exponential distribution with rate $\lambda = 0.4\,\text{sec}^{-1}$ ($T \sim \text{Exp}(0.4)$).
    \begin{enumerate}
        \item Compute the expected latency $\E[T]$ and standard deviation $\SD(T)$.
        \item Compute the probability that a query finishes in less than $2.5$ seconds: $\P(T \le 2.5)$.
        \item Compute the probability that a query takes longer than $5$ seconds: $\P(T > 5)$.
    \end{enumerate}

    \item \textbf{Memoryless Property in Technical Support:} Call duration with a technical support engineer follows an Exponential distribution with mean duration $\E[X] = 10$ minutes ($\lambda = 0.1$).
    \begin{enumerate}
        \item Given that a call has already lasted 15 minutes, what is the probability that it lasts at least an additional 10 minutes (total duration $\ge 25$ minutes)?
        \item Compare this to the unconditional probability that a fresh call lasts at least 10 minutes.
    \end{enumerate}

    \item \textbf{Data Science Modeling Architecture:} A data scientist models two distinct variables:
    \begin{itemize}
        \item Variable 1: The number of active transactions completed in the last hour.
        \item Variable 2: The exact continuous duration (in seconds) between two consecutive transactions.
    \end{itemize}
    Which variable should be modeled with a Poisson distribution, and which should be modeled with an Exponential distribution? Explain the mathematical duality between the two.
\end{enumerate}

\subsection*{Part B: Conceptual and Diagnostic Multiple Choice Questions}

\begin{enumerate}[resume]
\item \textbf{Conceptual Diagnostic: Probability Density Function Value Interpretation} \\
Let $X \sim \text{Uniform}(0, 0.25)$ be a continuous random variable. An engineering student evaluates the PDF at $x = 0.10$ and finds $f_X(0.10) = \frac{1}{0.25 - 0} = 4.0$. The student states: \textit{"This cannot be a valid probability distribution because the probability is $400\%$, which violates Kolmogorov's axioms."} Which of the following provides the \textbf{correct mathematical refutation}?
\begin{enumerate}
    \item The student is correct; the height of a PDF must never exceed $1.0$.
    \item The student is incorrect; $f_X(x)$ represents probability density, not probability. Only the integrated area under the PDF must equal $1.00$, and the area is $\int_0^{0.25} 4.0 \, dx = 1.00$.
    \item The student is incorrect because $f_X(x)$ is the cumulative distribution function, which is unbounded.
    \item The student is correct because continuous distributions cannot be evaluated on intervals shorter than $1.0$.
\end{enumerate}

\item \textbf{Conceptual Diagnostic: Memoryless Reliability Fallacy} \\
A reliability engineer models the lifespan of mechanical drone rotors using an Exponential distribution $\text{Exp}(\lambda)$. A fleet manager notices that rotors frequently suffer wear-and-tear degradation after 500 flight hours, with failure rates rising sharply between 500 and 600 hours. Why is the Exponential distribution a \textbf{fundamentally flawed model} for this physical system?
\begin{enumerate}
    \item Because the Exponential distribution has infinite support $[0, \infty)$, but drones have finite flight times.
    \item Because the Exponential distribution possesses the Memoryless Property ($\P(X > s + t \mid X > s) = \P(X > t)$), asserting that an old, worn rotor has the exact same failure probability as a brand-new rotor, directly contradicting the observed physical wear-out.
    \item Because the Exponential distribution only models discrete integers, whereas flight hours are continuous.
    \item Because the mean and variance of the Exponential distribution must be equal, which violates mechanical physics.
\end{enumerate}
\end{enumerate}
