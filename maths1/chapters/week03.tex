\chapter{Quadratic Functions and Optimization}
\index{Quadratic Functions}

Quadratic functions are second-degree polynomials that describe parabolic curves in coordinate space. In data science, machine learning, and econometrics, quadratic functions occupy a central position: Mean Squared Error (MSE) loss surfaces, $L_2$ (Ridge) regularization penalties, second-order Taylor expansions (Newton-Raphson optimization), and support vector objective duals are all fundamental quadratic formulations whose global minima can be computed with mathematical certainty.

\section{Quadratic Equations and Solving Methods}

\begin{lstlisting}[language=Python, caption=Data Science: Finding Roots of a Quadratic]
import numpy as np

# Define quadratic ax^2 + bx + c = 0
coefficients = [2, -8, 6] # 2x^2 - 8x + 6

# Find the roots
roots = np.roots(coefficients)
print(f'Roots: {roots}') # Outputs [3. 1.]
\end{lstlisting}


\begin{intuitionbox}{The U-Shape Curve}
While linear equations represent constant rates of change (straight lines), quadratic equations model acceleration, gravity, and optimization. Whenever you see a $x^2$, expect the graph to curve into a "U" shape (a parabola), which means it will inevitably hit a bottom or top point---the perfect spot for finding minimum costs or maximum profits!
\end{intuitionbox}

A quadratic equation is of the form:
$$ax^2 + bx + c = 0 \quad (\text{where } a, b, c \in \R \text{ and } a \neq 0)$$

\begin{formulabox}{Solving Quadratic Equations}
We can find the roots (solutions) using three main approaches:
\begin{enumerate}
    \item \textbf{Factoring:} Rewriting the equation as $a(x-r_1)(x-r_2) = 0$.
    \item \textbf{Completing the Square:} Expressing the equation in the form $(x-h)^2 = k$.
    \item \textbf{The Quadratic Formula:}
    $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
\end{enumerate}
\end{formulabox}

\textbf{Data Science Relevance:} Many optimization algorithms, such as Gradient Descent, are designed to find the roots or extrema of functions. While quadratics can be solved analytically using the formula above, more complex functions require iterative numeric solvers.

\subsection{Nature of Roots (The Discriminant)}

The term under the square root in the quadratic formula is the \textbf{discriminant}, denoted by $D$ (or $\Delta$):
$$D = b^2 - 4ac$$

\begin{theorembox}{Discriminant Properties}
For a quadratic equation with real coefficients:
\begin{itemize}
    \item If $D > 0$: The equation has \textbf{two distinct real roots}. The parabola crosses the x-axis twice.
    \item If $D = 0$: The equation has \textbf{one repeated real root} at $x = -\frac{b}{2a}$. The parabola just touches the x-axis.
    \item If $D < 0$: The equation has \textbf{two complex conjugate roots} ($x = \frac{-b \pm i\sqrt{|D|}}{2a}$). The graph does not touch the x-axis.
\end{itemize}
\end{theorembox}

\section{Geometry of the Parabola}

The graph of a quadratic function $f(x) = ax^2 + bx + c$ is a \textbf{parabola}.

\begin{definitionbox}{Parabolic Characteristics}
\begin{itemize}
    \item \textbf{Direction of Opening:} 
        \begin{itemize}
            \item If $a > 0$, the parabola opens \textbf{upward} (convex).
            \item If $a < 0$, the parabola opens \textbf{downward} (concave).
        \end{itemize}
    \item \textbf{Vertex ($V$):} The turning point of the parabola. The vertex coordinates are:
    $$V(h, k) = \left( -\frac{b}{2a}, \, f\left(-\frac{b}{2a}\right) \right) = \left( -\frac{b}{2a}, \, -\frac{b^2 - 4ac}{4a} \right)$$
    \item \textbf{Vertex Form:} Any quadratic function can be written as:
    $$f(x) = a(x - h)^2 + k$$
    where $(h, k)$ is the vertex.
    \item \textbf{Axis of Symmetry:} The vertical line passing through the vertex:
    $$x = -\frac{b}{2a}$$
\end{itemize}
\end{definitionbox}

\begin{examplebox}{Completing the Square and Graphing}
Convert the function $f(x) = 2x^2 - 8x + 6$ into vertex form, find its vertex, axis of symmetry, and intercepts.
\begin{enumerate}
    \item Factor out the coefficient $a=2$ from the variable terms:
    $$f(x) = 2(x^2 - 4x) + 6$$
    \item Complete the square inside the parenthesis. Half of $-4$ is $-2$, and $(-2)^2 = 4$. Add and subtract $4$:
    $$f(x) = 2(x^2 - 4x + 4 - 4) + 6 = 2((x-2)^2 - 4) + 6$$
    $$f(x) = 2(x-2)^2 - 8 + 6 \implies f(x) = 2(x-2)^2 - 2$$
    \item \textbf{Vertex ($h, k$):} The vertex is $(2, -2)$. Since $a = 2 > 0$, it is a minimum point.
    \item \textbf{Axis of Symmetry:} The vertical line $x = 2$.
    \item \textbf{Intercepts:}
    \begin{itemize}
        \item y-intercept: $f(0) = 2(0)^2 - 8(0) + 6 = 6 \implies (0, 6)$.
        \item x-intercepts: Set $f(x) = 0 \implies 2(x-2)^2 - 2 = 0 \implies 2(x-2)^2 = 2 \implies (x-2)^2 = 1 \implies x-2 = \pm 1$.
        So $x = 3$ or $x = 1$. Thus, intercepts are $(1, 0)$ and $(3, 0)$.
    \end{itemize}
\end{enumerate}
\end{examplebox}

\section{Optimization Applications}

Because quadratics have a single extremum at their vertex, optimization is straightforward. This is why loss functions like Mean Squared Error (MSE) are formulated quadratically: they guarantee a single, easily discoverable minimum.

\begin{theorembox}{Quadratic Extremum}
For the function $f(x) = ax^2 + bx + c$:
\begin{itemize}
    \item If $a > 0$, $f(x)$ achieves its \textbf{global minimum} value of $-\frac{D}{4a}$ at $x = -\frac{b}{2a}$.
    \item If $a < 0$, $f(x)$ achieves its \textbf{global maximum} value of $-\frac{D}{4a}$ at $x = -\frac{b}{2a}$.
\end{itemize}
\end{theorembox}

\begin{examplebox}{Business Revenue Optimization}
A company's daily profit is modeled by $P(x) = -10x^2 + 1200x - 2000$, where $x$ is the price of their product in dollars. Find the price that maximizes profit, and calculate that maximum profit.
\begin{itemize}
    \item Here, $a = -10 < 0$ and $b = 1200$. Since $a < 0$, the profit function is a downward-opening parabola, meaning it has a maximum at its vertex.
    \item The maximizing price $x$ is:
    $$x = -\frac{b}{2a} = -\frac{1200}{2(-10)} = \frac{1200}{20} = 60 \text{ dollars}$$
    \item The maximum profit is $P(60)$:
    $$P(60) = -10(60)^2 + 1200(60) - 2000 = -10(3600) + 72000 - 2000$$
    $$P(60) = -36000 + 72000 - 2000 = 34000 \text{ dollars}$$
\end{itemize}
So, setting the price to $\$60$ maximizes daily profit at $\$34,000$.
\end{examplebox}

\section{Vieta's Formulas and Symmetric Polynomials}

For any quadratic equation $a x^2 + b x + c = 0$ with roots $r_1$ and $r_2$, Vieta's formulas directly relate the roots to the algebraic coefficients without requiring explicit factorization:
\begin{align*}
    r_1 + r_2 &= -\frac{b}{a} \\
    r_1 \cdot r_2 &= \frac{c}{a}
\end{align*}
Using these fundamental relations, any symmetric polynomial in the roots can be evaluated directly:
\begin{itemize}
    \item \textbf{Sum of Squares:} $r_1^2 + r_2^2 = (r_1 + r_2)^2 - 2 r_1 r_2 = \left(-\frac{b}{a}\right)^2 - 2\left(\frac{c}{a}\right) = \frac{b^2 - 2ac}{a^2}$.
    \item \textbf{Sum of Cubes:} $r_1^3 + r_2^3 = (r_1 + r_2)(r_1^2 - r_1 r_2 + r_2^2) = (r_1 + r_2)\left[(r_1 + r_2)^2 - 3 r_1 r_2\right]$.
    \item \textbf{Difference of Roots:} $|r_1 - r_2| = \sqrt{(r_1 + r_2)^2 - 4 r_1 r_2} = \frac{\sqrt{b^2 - 4ac}}{|a|} = \frac{\sqrt{\Delta}}{|a|}$.
\end{itemize}

\section{Common Pitfalls, Traps \& Misconceptions}

\begin{trapbox}{Trap 1: The Parabolic Concavity vs. Convexity Sign Trap}
A frequent conceptual inversion is confusing $a > 0$ with a maximum and $a < 0$ with a minimum.
\begin{itemize}
    \item If $a > 0$, the parabola opens \textbf{upward} (strictly convex, $\frac{d^2 f}{dx^2} = 2a > 0$). The vertex is the unique \textbf{global minimum}. There is no maximum ($f(x) \to +\infty$).
    \item If $a < 0$, the parabola opens \textbf{downward} (strictly concave, $\frac{d^2 f}{dx^2} = 2a < 0$). The vertex is the unique \textbf{global maximum}. There is no minimum ($f(x) \to -\infty$).
    \item In Machine Learning loss minimization, our objective functions \textbf{must} have $a > 0$; otherwise gradient descent diverges to $-\infty$!
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 2: The Vertex $y$-Coordinate Formula Sign}
When using the algebraic shortcut for the vertex extremum value $k$:
$$k = f\left(-\frac{b}{2a}\right) = c - \frac{b^2}{4a} = -\frac{b^2 - 4ac}{4a} = -\frac{\Delta}{4a}$$
Notice the critical minus sign preceding $\Delta$. Forgetting this negative sign produces an inverted value for the optimal loss or maximum profit.
\end{trapbox}

\begin{trapbox}{Trap 3: Discriminant Negative $\Delta < 0$ and Strict Positivity}
When $\Delta = b^2 - 4ac < 0$, students often incorrectly state that the function "has no values."
\begin{itemize}
    \item $\Delta < 0$ strictly means that $f(x) = 0$ has \textbf{no real roots} (the parabola never intersects the $x$-axis).
    \item If $a > 0$ and $\Delta < 0$, the entire parabola floats strictly above the $x$-axis: $f(x) > 0$ for \textbf{all} $x \in \R$.
    \item In Data Science, this condition guarantees that a regularized loss function remains strictly positive and bounded away from zero.
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 4: Boundary-Constrained Optimization Traps}
When optimizing a quadratic over a closed interval $[x_1, x_2]$, the global unconstrained vertex $x^* = -\frac{b}{2a}$ is only the solution if $x^* \in [x_1, x_2]$.
\begin{itemize}
    \item If the vertex lies outside the interval ($x^* \notin [x_1, x_2]$), the true constrained minimum and maximum occur strictly at the boundary endpoints $x_1$ and $x_2$.
    \item Always check: (1) Is $x^* \in [x_1, x_2]$? If yes, compare $f(x^*)$ with $f(x_1)$ and $f(x_2)$. If no, the extremum must be at an endpoint.
\end{itemize}
\end{trapbox}

\section{Python Implementation: Symbolic Quadratics, Loss Curves, and Ridge Shrinkage}

\begin{lstlisting}[caption={Quadratic Analysis and Optimization in Python}]
import numpy as np
import sympy as sp

# 1. Symbolic Vertex Form and Vieta Verification with SymPy
x, a, b, c = sp.symbols('x a b c', real=True)
quad_expr = 2*x**2 - 7*x + 3

# Compute exact analytical roots
roots = sp.solve(quad_expr, x)
r1, r2 = roots[0], roots[1]
print(f"Roots: r1 = {r1}, r2 = {r2}")

# Vieta Verification
sum_roots = r1 + r2
prod_roots = r1 * r2
print(f"Vieta Sum: {sum_roots} (Matches -b/a = 7/2: {sum_roots == sp.Rational(7, 2)})")
print(f"Vieta Prod: {prod_roots} (Matches c/a = 3/2: {prod_roots == sp.Rational(3, 2)})")

# 2. Ridge Regularization Shrinkage Simulation
# Objective: L(w) = 0.5*(w - 4)^2 + 0.5*lambda*w^2 -> min over w
# Standard form: 0.5*(1 + lambda)*w^2 - 4*w + 8
lambdas = [0.0, 0.5, 1.0, 5.0, 10.0]
print("\nRidge Regularization Weight Shrinkage:")
for lmb in lambdas:
    # a_opt = 0.5 * (1 + lmb), b_opt = -4
    # w_star = -b / (2*a) = 4 / (1 + lmb)
    w_star = 4.0 / (1.0 + lmb)
    min_loss = 0.5 * (w_star - 4.0)**2 + 0.5 * lmb * (w_star**2)
    print(f"  Lambda = {lmb:4.1f} -> Optimal w* = {w_star:.4f}, Min Loss = {min_loss:.4f}")

# 3. Constrained Optimization on Compact Interval [3, 5]
# Function: f(x) = -3*x^2 + 12*x - 5. Unconstrained vertex at x = -12 / (2*-3) = 2.
# Since vertex x=2 is NOT in [3, 5], evaluate endpoints!
x_vals = np.array([3.0, 5.0])
f_vals = -3*x_vals**2 + 12*x_vals - 5
print(f"\nConstrained Interval [3, 5]:")
print(f"f(3) = {f_vals[0]}, f(5) = {f_vals[1]}")
print(f"Max on [3, 5] is {np.max(f_vals)} at x=3.0; Min is {np.min(f_vals)} at x=5.0")
\end{lstlisting}

\subsection*{Part A: Computational and Analytical Problems}

\begin{enumerate}
    \item \textbf{Vieta's Relations and Polynomial Transformation:} The quadratic equation:
    $$2x^2 - 7x + 3 = 0$$
    has roots denoted by $r_1$ and $r_2$.
    \begin{enumerate}
        \item State the values of $r_1 + r_2$ and $r_1 r_2$ directly using Vieta's formulas.
        \item Solve the equation analytically to verify the individual roots.
        \item Construct a new monic quadratic polynomial whose roots are $r_1^2$ and $r_2^2$.
        \item Calculate the value of the symmetric sum of cubes $r_1^3 + r_2^3$ without taking cubes of decimals.
    \end{enumerate}

    \item \textbf{Vertex Form and Interval-Constrained Optimization:} Consider the quadratic function:
    $$f(x) = -3x^2 + 12x - 5$$
    \begin{enumerate}
        \item Convert $f(x)$ into vertex form $a(x - h)^2 + k$ via completing the square.
        \item State the coordinates of the unconstrained vertex extremum, and specify whether it is a global minimum or maximum.
        \item Find the absolute maximum and minimum values of $f(x)$ on the restricted interval $[3, 5]$.
        \item Find the absolute maximum and minimum values of $f(x)$ on the restricted interval $[-2, 1]$.
    \end{enumerate}

    \item \textbf{Convex Quadratic Loss and Ridge ($L_2$) Regularization:} In machine learning, a regularized parameter estimation problem minimizes the penalized loss function:
    $$L(w) = \frac{1}{2}(w - 4)^2 + \frac{\lambda}{2} w^2, \qquad \text{where } \lambda \ge 0$$
    \begin{enumerate}
        \item Expand and collect terms to express $L(w)$ in standard quadratic form $a w^2 + b w + c$.
        \item Prove that $L(w)$ is strictly convex for all $\lambda \ge 0$.
        \item Derive the optimal parameter $w^*(\lambda)$ as a function of regularization strength $\lambda$.
        \item Demonstrate the mathematical shrinkage property by evaluating $\lim_{\lambda \to 0} w^*(\lambda)$ and $\lim_{\lambda \to \infty} w^*(\lambda)$.
        \item For $\lambda = 0.5$, compute the numerical optimal weight $w^*$ and the corresponding minimum loss $L(w^*)$.
    \end{enumerate}

    \item \textbf{Discriminant Analysis and Strictly Positive Quadratic Forms:} Consider the parameterized family of quadratic expressions:
    $$g(x) = k x^2 + 6x + (k - 8)$$
    \begin{enumerate}
        \item Formulate the discriminant $\Delta(k)$ in terms of parameter $k$.
        \item Find the values of $k$ for which the equation $g(x) = 0$ has exactly one repeated real root.
        \item Determine the complete range of values of $k$ for which $g(x)$ remains strictly positive ($g(x) > 0$) for all real numbers $x \in \mathbb{R}$.
    \end{enumerate}

    \item \textbf{Mean Squared Error (MSE) Parameter Estimation:} A linear regression model passing through the origin is given by $\hat{y} = w x$. Given training observations:
    $$\{(1, 3), (2, 5), (3, 8)\}$$
    \begin{enumerate}
        \item Express the empirical Mean Squared Error loss $L(w) = \frac{1}{3} \sum_{i=1}^3 (y_i - w x_i)^2$ explicitly as a quadratic function in $w$.
        \item Determine the optimal parameter weight $w^*$ that minimizes the MSE loss.
        \item Compute the minimum Mean Squared Error achievable by this model.
    \end{enumerate}
\end{enumerate}

\subsection*{Part B: Conceptual and Diagnostic Multiple Choice Questions}

\begin{enumerate}[resume]
\item \textbf{Conceptual Diagnostic: Parabola Extrema and Strict Positivity} \\
Let $f(x) = a x^2 + b x + c$ be a quadratic function with real coefficients. If the discriminant satisfies $\Delta = b^2 - 4ac < 0$ and $a > 0$, which of the following statements is \textbf{strictly correct}?
\begin{enumerate}
    \item $f(x)$ has no real values and is mathematically undefined.
    \item $f(x)$ possesses a global maximum at $x = -\frac{b}{2a}$, and the graph intersects the $x$-axis twice.
    \item $f(x)$ has a unique global minimum at $x = -\frac{b}{2a}$, and $f(x) > 0$ strictly for all real numbers $x \in \mathbb{R}$.
    \item $f(x)$ is strictly negative for all $x \in \mathbb{R}$ because $\Delta < 0$.
\end{enumerate}

\item \textbf{Conceptual Diagnostic: Ridge Regularization Shrinkage Mechanism} \\
In Ridge regression with quadratic objective $L(w) = \frac{1}{2}(w - w_{\text{OLS}})^2 + \frac{\lambda}{2} w^2$, how does increasing the regularization hyperparameter $\lambda > 0$ affect the optimal parameter $w^*(\lambda) = \frac{w_{\text{OLS}}}{1 + \lambda}$?
\begin{enumerate}
    \item It causes $w^*$ to oscillate sinusoidally between $+w_{\text{OLS}}$ and $-w_{\text{OLS}}$.
    \item It smoothly shrinks the magnitude of $w^*$ monotonically toward zero without ever setting it exactly to zero for finite $\lambda$.
    \item It sets $w^*$ strictly to zero as soon as $\lambda \ge 1.0$, identical to Lasso ($L_1$) regularization.
    \item It inflates the variance of $w^*$, making the model more prone to overfitting.
\end{enumerate}
\end{enumerate}
