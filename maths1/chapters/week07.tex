Calculus is the mathematical study of continuous variation and dynamical change. The entire superstructure of differential calculus—slopes, instantaneous velocities, gradients, and backpropagation—is constructed on the foundation of the \textbf{limit}. In data science and machine learning, limits govern the convergence of iterative algorithms (such as gradient descent), formalize learning rate bounds, and define the derivatives that steer predictive parameter optimization.

\section{Sequences and Convergence}

import sympy as sp

x = sp.Symbol('x')
f = (x**2 - 1)/(x - 1)

# Limit as x -> 1

\begin{intuitionbox}{The Ultimate Destination}
Limits ask a simple but profound question: "If I keep taking steps along a path forever, where am I eventually going to end up?" Whether you are looking at the terms of a sequence, or the values of a function as $x$ gets larger, a limit describes the inevitable destination (if one exists), even if you never actually reach it.
\end{intuitionbox}

A \textbf{sequence} is an ordered list of numbers. Formally, it can be viewed as a function whose domain is the set of natural numbers $\N$, written as:
$$a_1, a_2, a_3, \dots, a_n, \dots \quad \text{or } \set{a_n}_{n=1}^{\infty}$$
where $a_n$ represents the $n$-th term of the sequence.

\begin{definitionbox}{Limit of a Sequence}
A sequence $\set{a_n}$ has the limit $L$ (written as $\limit{n}{\infty} a_n = L$) if the terms $a_n$ get arbitrarily close to $L$ as $n$ grows to infinity.
\begin{itemize}
    \item \textbf{Convergent:} If the limit exists and is a finite real number $L$.
    \item \textbf{Divergent:} If the limit does not exist (e.g., the terms grow without bound toward $\pm\infty$, or they oscillate back and forth indefinitely).
\end{itemize}
\end{definitionbox}

\textbf{Data Science Relevance:} In machine learning, training an algorithm like a neural network involves minimizing a loss function over multiple iterations (epochs). The sequence of loss values $\set{L_1, L_2, L_3, \dots, L_n}$ as training progresses must ideally \textbf{converge} to a minimum value. If the loss sequence \textit{diverges}, the model has failed to learn (often due to a learning rate that is too high).

\begin{theorembox}{Limit Laws for Sequences}
If $\set{a_n}$ and $\set{b_n}$ are convergent sequences with $\limit{n}{\infty} a_n = A$ and $\limit{n}{\infty} b_n = B$:
\begin{itemize}
    \item $\limit{n}{\infty} (a_n \pm b_n) = A \pm B$
    \item $\limit{n}{\infty} (a_n \cdot b_n) = A \cdot B$
    \item $\limit{n}{\infty} \left(\frac{a_n}{b_n}\right) = \frac{A}{B}$ (provided $b_n \neq 0$ and $B \neq 0$)
    \item $\limit{n}{\infty} c = c$ (for any constant $c$)
\end{itemize}
\end{theorembox}

\begin{examplebox}{Sequence Convergence Check}
Determine if the sequence $a_n = \frac{4n^2 - 3n}{2n^2 + 5n + 1}$ converges, and find its limit.
\begin{itemize}
    \item Divide both the numerator and denominator by the highest power of $n$ (which is $n^2$):
    $$a_n = \frac{\frac{4n^2}{n^2} - \frac{3n}{n^2}}{\frac{2n^2}{n^2} + \frac{5n}{n^2} + \frac{1}{n^2}} = \frac{4 - \frac{3}{n}}{2 + \frac{5}{n} + \frac{1}{n^2}}$$
    \item Take the limit as $n \to \infty$. Note that as $n$ grows infinitely large, any fraction with $n$ in the denominator shrinks to $0$ ($\limit{n}{\infty} \frac{1}{n} = 0$):
    $$\limit{n}{\infty} a_n = \frac{4 - 0}{2 + 0 + 0} = \frac{4}{2} = 2$$
    \item Since the limit is a finite number, the sequence \textbf{converges} to $2$.
\end{itemize}
\end{examplebox}

\section{Rates of Change and Secant Lines}

Let $y = f(x)$ be a function representing some changing quantity (e.g., position over time).

\begin{definitionbox}{Average Rate of Change and Secants}
\begin{itemize}
    \item The \textbf{average rate of change} of $f(x)$ over the interval $[x_1, x_2]$ is the ratio of change in output to change in input:
    $$\text{Average Rate of Change} = \frac{\Delta y}{\Delta x} = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$$
    \item Geometrically, this ratio is the slope of the \textbf{secant line} that connects the two points $(x_1, f(x_1))$ and $(x_2, f(x_2))$ on the graph of $f$.
\end{itemize}
\end{definitionbox}

\section{Tangents as Limits of Secants}

If we want to find the \textit{instantaneous} rate of change at exactly one point $x_1 = c$, we can't use the secant formula directly because $\frac{f(c) - f(c)}{c - c} = \frac{0}{0}$, which is undefined. 

Instead, we let the second point $x_2$ get closer and closer to $c$. Let the difference between them be $h$ (so $x_2 = c + h$). As $h \to 0$, the secant line approaches the \textbf{tangent line} at $c$.

\begin{definitionbox}{Tangent Line Slope (The Derivative)}
The slope of the tangent line to the curve $y = f(x)$ at the point $(c, f(c))$ is the limit of the secant slopes as $h \to 0$:
$$m_{\text{tan}} = \limit{h}{0} \frac{f(c + h) - f(c)}{h}$$
This instantaneous slope is the foundation of the \textbf{derivative}.
\end{definitionbox}

\textbf{Data Science Relevance:} In Gradient Descent, we want to slide down a loss curve to find its bottom. To do this, we need to know the slope of the tangent line at our current position. The limit formula above is exactly how that slope is mathematically defined!

\begin{examplebox}{Finding Tangent Slope using Limits}
Find the slope of the tangent line to the curve $f(x) = x^2 + 2x$ at $x = 3$.
\begin{enumerate}
    \item Set up the limit for the slope at $c = 3$:
    $$m_{\text{tan}} = \limit{h}{0} \frac{f(3+h) - f(3)}{h}$$
    \item Compute the output at our target point: $f(3) = 3^2 + 2(3) = 9 + 6 = 15$.
    \item Compute the output slightly offset by $h$:
    $$f(3+h) = (3+h)^2 + 2(3+h) = (9 + 6h + h^2) + (6 + 2h) = h^2 + 8h + 15$$
    \item Substitute back into the limit:
    $$m_{\text{tan}} = \limit{h}{0} \frac{(h^2 + 8h + 15) - 15}{h} = \limit{h}{0} \frac{h^2 + 8h}{h}$$
    \item Factor out $h$ to resolve the division by zero issue:
    $$m_{\text{tan}} = \limit{h}{0} \frac{h(h + 8)}{h} = \limit{h}{0} (h + 8) = 8$$
\end{enumerate}
So, the instantaneous slope of the tangent line to $x^2 + 2x$ at exactly $x=3$ is $8$.
\end{examplebox}

\section{Common Pitfalls, Traps \& Misconceptions}

\begin{trapbox}{Trap 1: The Indeterminate Form Fallacy $\left[\frac{0}{0}\right]$}
When substituting $h = 0$ into a difference quotient $\frac{f(x+h) - f(x)}{h}$, students often arrive at $\frac{0}{0}$ and conclude that the limit is undefined or equals $1$.
\begin{itemize}
    \item $\frac{0}{0}$ is an \textbf{indeterminate form}. It does \textbf{not} mean the limit does not exist!
    \item It indicates that an algebraic cancellation is required: factor out $h$ from the numerator to cancel the denominator, rationalize radicals using conjugates, or expand terms.
    \item Once the zero-factor $h$ is cancelled, the true finite instantaneous slope emerges cleanly.
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 2: Average Rate of Change vs. Instantaneous Rate of Change}
Confusing the slope of a secant line across an interval with the derivative at a point is a major misconception.
\begin{itemize}
    \item \textbf{Average Rate of Change:} $\frac{f(b) - f(a)}{b - a}$ depends on \textbf{two points} across a macro interval $[a, b]$ (Secant slope).
    \item \textbf{Instantaneous Rate of Change:} $f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$ is evaluated at \textbf{one point} (Tangent slope).
    \item For non-linear curves, the average rate across $[1, 5]$ rarely equals the instantaneous derivative at $x = 1$ or $x = 5$.
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 3: Sequence Domain ($\mathbb{N}$) vs. Real Variable Function Domain ($\mathbb{R}$)}
Students sometimes claim that a sequence limit $\lim_{n \to \infty} a_n$ is identical in every way to the real variable limit $\lim_{x \to \infty} f(x)$.
\begin{itemize}
    \item A sequence is restricted to discrete integer inputs $n \in \{1, 2, 3, \dots\}$.
    \item \textbf{Classic Trap:} Let $a_n = \sin(\pi n)$. Because $\sin(\pi n) = 0$ for all integers $n$, the sequence $\lim_{n \to \infty} a_n = 0$ converges cleanly!
    \item However, for continuous $x \in \mathbb{R}$, $\lim_{x \to \infty} \sin(\pi x)$ does \textbf{not exist} (it oscillates indefinitely between $-1$ and $+1$).
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 4: Gradient Descent Sequence Divergence via Learning Rate Overshoot}
Gradient descent updates follow the sequence: $w_{t+1} = w_t - \eta f'(w_t)$.
\begin{itemize}
    \item For a quadratic loss $f(w) = \frac{1}{2} L w^2$, the derivative is $f'(w) = L w$.
    \item The update sequence becomes: $w_{t+1} = w_t - \eta L w_t = (1 - \eta L) w_t$.
    \item By geometric progression, $w_t = (1 - \eta L)^t w_0$.
    \item \textbf{Convergence Criterion:} The sequence converges if and only if $|1 - \eta L| < 1 \implies \mathbf{0 < \eta < \frac{2}{L}}$.
    \item If $\eta > \frac{2}{L}$, the sequence oscillations explode exponentially toward $\pm \infty$. Setting the learning rate appropriately is a direct application of sequence convergence!
\end{itemize}
\end{trapbox}

\section{Python Implementation: Difference Quotients and Gradient Descent Dynamics}

\begin{lstlisting}[caption={Numerical Secants, First-Principles Tangents, and GD Convergence in Python}]
import numpy as np
import sympy as sp

# 1. First-Principles Numerical Derivative vs. Analytical Value
# Function: f(x) = x^3 - 4x + 1. Target point: x = 2.0. Analytical f'(2) = 3(2)^2 - 4 = 8.0
def f_func(x):
    return x**3 - 4*x + 1

x_target = 2.0
h_steps = [1.0, 0.1, 0.01, 1e-4, 1e-7]

print("Approaching the Instantaneous Tangent Slope as h -> 0:")
for h in h_steps:
    secant_slope = (f_func(x_target + h) - f_func(x_target)) / h
    error = abs(secant_slope - 8.0)
    print(f"  h = {h:7.1e} -> Secant Slope = {secant_slope:10.6f} | Abs Error = {error:8.2e}")

# 2. Symbolic Limit Resolution of [0/0] Indeterminate Form with SymPy
x, h = sp.symbols('x h', real=True)
diff_quotient = ((x + h)**3 - 4*(x + h) + 1 - (x**3 - 4*x + 1)) / h

tangent_expr = sp.limit(diff_quotient, h, 0)
print(f"\nAnalytical First-Principles Derivative f'(x): {tangent_expr}")
print(f"Evaluated at x = 2.0:                         {tangent_expr.subs(x, 2.0)}")

# 3. Gradient Descent Sequence Convergence vs. Divergence
# Loss: L(w) = 0.5 * L_curv * w^2 with L_curv = 4.0. Critical bound: eta_crit = 2 / 4.0 = 0.50
L_curv = 4.0
w_init = 10.0
eta_stable   = 0.35  # Stable: |1 - 0.35*4| = |1 - 1.4| = 0.4 < 1
eta_unstable = 0.55  # Divergent: |1 - 0.55*4| = |1 - 2.2| = 1.2 > 1

def run_gd(eta, steps=6):
    w = w_init
    seq = [w]
    for _ in range(steps):
        w = w - eta * (L_curv * w)
        seq.append(w)
    return seq

print("\nGradient Descent Sequence Trajectory:")
print("  Stable (eta=0.35):  ", [round(val, 3) for val in run_gd(eta_stable)])
print("  Divergent (eta=0.55):", [round(val, 3) for val in run_gd(eta_unstable)])
\end{lstlisting}

\subsection*{Part B: Conceptual and Diagnostic Multiple Choice Questions}

\begin{enumerate}[resume]
\item \textbf{Conceptual Diagnostic: Resolving the Indeterminate Difference Quotient} \\
When evaluating the instantaneous rate of change $f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$, direct substitution of $h = 0$ yields the expression $\left[\frac{0}{0}\right]$. An analytics student claims: \textit{"Because $\frac{0}{0}$ is undefined, the derivative cannot be computed at any point."} What is the \textbf{correct mathematical refutation}?
\begin{enumerate}
    \item The student is correct; derivatives are merely heuristics and have no formal mathematical value.
    \item The student is incorrect because $\frac{0}{0}$ always equals $1.0$ by arithmetic division rules.
    \item The student is incorrect because $\left[\frac{0}{0}\right]$ is an \textbf{indeterminate form}, not a fixed value; it indicates that the factor $h$ in the denominator cancels algebraically with a factor of $h$ extracted from the numerator, allowing the finite limiting slope to be evaluated.
    \item The student is incorrect because $h$ is never allowed to be smaller than $0.001$.
\end{enumerate}

\item \textbf{Conceptual Diagnostic: Learning Rate Convergence Boundary in Gradient Descent} \\
For a strictly convex quadratic objective function $f(w) = \frac{1}{2} L w^2$ where $L > 0$ represents the maximum curvature, gradient descent parameter updates evolve according to $w_{t+1} = (1 - \eta L) w_t$. What happens to the parameter sequence $\set{w_t}$ if the data scientist selects an aggressive learning rate $\eta = \frac{2.5}{L}$?
\begin{enumerate}
    \item The sequence converges to $0$ in fewer than 3 steps because the learning rate is large.
    \item The contraction factor satisfies $|1 - \eta L| = |1 - 2.5| = |-1.5| = 1.5 > 1.0$; the sequence oscillates with alternating signs and **diverges exponentially** ($|w_t| \to \infty$).
    \item The parameter remains frozen at its initial value $w_0$.
    \item The model converges to a suboptimal local minimum.
\end{enumerate}
\end{enumerate}
