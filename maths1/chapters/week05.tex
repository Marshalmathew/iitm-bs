\chapter{Functions, Compositions, and Exponentials}
\index{Functions, Compositions, and Exponentials}

This chapter deepens the theory of mathematical mappings, investigating how operations can be combined sequentially (compositions), reversed (inverses), and exponentially scaled. In modern machine learning and data science, composite functions form the architectural backbone of deep neural networks (where layers of matrix transformations and non-linear activations are chained), while exponential and logarithmic functions power probabilistic classifiers (logistic regression, sigmoid, and softmax functions).

\begin{intuitionbox}{Visualizing the Rules of Functions}
A function is like a reliable machine: if you give it the same input, it must always produce the same output. Geometrically, the Vertical Line Test is just checking if any $x$-value (input) accidentally spits out two different $y$-values (outputs). If it does, the machine is broken (it's not a function)!
\end{intuitionbox}

Graphs are an excellent way to visually analyze the properties of functions and mappings. We use two geometric tests:

\begin{theorembox}{Line Tests for Functions}
\begin{itemize}
    \item \textbf{Vertical Line Test (Function Existence):} A curve in the Cartesian plane represents a valid function $y = f(x)$ if and only if \textbf{no vertical line} intersects the curve at more than one point. If a vertical line hits twice, one input $x$ is mapping to multiple outputs, which violates the definition of a function.
    \item \textbf{Horizontal Line Test (One-to-One / Injectivity):} A function $y = f(x)$ is one-to-one (injective) if and only if \textbf{no horizontal line} intersects its graph at more than one point. If a horizontal line hits twice, multiple inputs map to the same output.
\end{itemize}
\end{theorembox}

\section{Composite Functions}

Composition is the process of applying one function to the results of another.

\begin{definitionbox}{Composite Function}
Let $\func{g}{A}{B}$ and $\func{f}{B}{C}$ be functions. The \textbf{composite function} $f \circ g$ (read "$f$ of $g$") is a function from $A$ to $C$ defined by:
$$(f \circ g)(x) = f(g(x))$$
The domain of $f \circ g$ is the set of all $x$ in the domain of $g$ such that $g(x)$ lies in the domain of $f$:
$$\text{Domain}(f \circ g) = \{ x \in \text{Domain}(g) \mid g(x) \in \text{Domain}(f) \}$$
\end{definitionbox}

\textbf{Data Science Relevance:} Artificial Neural Networks (Deep Learning) are fundamentally massive chains of composite functions. The output of one layer of neurons ($g(x)$) becomes the direct input for the next layer ($f(g(x))$). By chaining simple functions together, networks can approximate incredibly complex boundaries.

\begin{examplebox}{Function Composition and Domain}
Let $f(x) = \sqrt{x}$ and $g(x) = x - 3$. Find $(f \circ g)(x)$ and its domain.
\begin{itemize}
    \item Find the expression:
    $$(f \circ g)(x) = f(g(x)) = f(x - 3) = \sqrt{x - 3}$$
    \item Find the domain:
    The domain of $g(x)$ is all real numbers $\R$.
    The domain of $f(t) = \sqrt{t}$ requires $t \ge 0$.
    Therefore, we require $g(x) \ge 0 \implies x - 3 \ge 0 \implies x \ge 3$.
    Thus, the domain of $f \circ g$ is $[3, \infty)$.
\end{itemize}
\end{examplebox}

\section{Inverse Functions}

An inverse function reverses the mapping of the original function.

\begin{definitionbox}{Inverse Function}
If $\func{f}{A}{B}$ is a \textbf{bijection} (both one-to-one and onto), then there exists a unique function $\func{f^{-1}}{B}{A}$ called the \textbf{inverse of $f$} such that:
$$f^{-1}(y) = x \iff f(x) = y \quad \forall y \in B$$
Key properties:
\begin{itemize}
    \item $\text{Domain}(f^{-1}) = \text{Range}(f)$ and $\text{Range}(f^{-1}) = \text{Domain}(f)$.
    \item $f(f^{-1}(y)) = y$ and $f^{-1}(f(x)) = x$.
    \item The graph of $f^{-1}$ is the reflection of the graph of $f$ across the diagonal line $y = x$.
\end{itemize}
\end{definitionbox}

\begin{examplebox}{Finding an Inverse Function}
Find the inverse of the function $f(x) = \frac{2x - 1}{x + 3}$ defined for $x \neq -3$.
\begin{enumerate}
    \item Write $y = f(x)$:
    $$y = \frac{2x - 1}{x + 3}$$
    \item Solve for $x$ in terms of $y$:
    $$y(x + 3) = 2x - 1 \implies xy + 3y = 2x - 1$$
    Collect all terms with $x$:
    $$xy - 2x = -3y - 1 \implies x(y - 2) = -(3y + 1) \implies x = \frac{3y + 1}{2 - y}$$
    \item Swap the variables to write $f^{-1}(x)$:
    $$f^{-1}(x) = \frac{3x + 1}{2 - x} \quad (\text{defined for } x \neq 2)$$
\end{enumerate}
\end{examplebox}

\section{Exponential Functions}

An exponential function is a function where the variable is placed in the exponent, leading to extremely rapid growth (or decay).

\begin{definitionbox}{Exponential Function}
An exponential function is of the form:
$$f(x) = a^x \quad (\text{where } a > 0 \text{ and } a \neq 1)$$
\begin{itemize}
    \item \textbf{Domain:} $(-\infty, \infty)$ (all real numbers).
    \item \textbf{Range:} $(0, \infty)$ (always strictly positive, never $0$).
    \item \textbf{Natural Exponential Function:} When the base is Euler's number $e \approx 2.71828$:
    $$f(x) = e^x$$
\end{itemize}
\end{definitionbox}

\begin{theorembox}{Laws of Exponents}
For $a > 0$ and any real numbers $x, y$:
\begin{itemize}
    \item $a^x \cdot a^y = a^{x+y}$
    \item $\frac{a^x}{a^y} = a^{x-y}$
    \item $(a^x)^y = a^{xy}$
    \item $(ab)^x = a^x b^x$
\end{itemize}
\end{theorembox}

\textbf{Data Science Relevance:} The natural exponential $e^x$ is pervasive in probability, statistics, and machine learning (especially Logistic Regression and the Softmax function) because its rate of growth is exactly equal to its current value—a unique and mathematically elegant property.

\subsection{The Sigmoid (Logistic) Function and Logit Link}
In binary classification (Logistic Regression), real-valued linear score outputs $z = \mathbf{w}^T \mathbf{x} + b \in (-\infty, \infty)$ must be mapped monotonically into a valid probability $p \in (0, 1)$. This mapping is achieved by the \textbf{Sigmoid function} $\sigma(z)$:
$$\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}$$
\begin{itemize}
    \item \textbf{Asymptotic Bounds:} $\lim_{z \to \infty} \sigma(z) = 1.0$, and $\lim_{z \to -\infty} \sigma(z) = 0.0$.
    \item \textbf{Centering Point:} $\sigma(0) = \frac{1}{1 + 1} = 0.50$ (the decision boundary threshold).
    \item \textbf{Point Symmetry:} $\sigma(-z) = 1 - \sigma(z)$ for all $z \in \mathbb{R}$.
    \item \textbf{The Inverse Mapping (Logit Function):} Solving $p = \sigma(z)$ for $z$:
    $$p = \frac{1}{1 + e^{-z}} \implies 1 + e^{-z} = \frac{1}{p} \implies e^{-z} = \frac{1 - p}{p} \implies e^z = \frac{p}{1 - p}$$
    Taking the natural logarithm yields the \textbf{logit function} (log-odds):
    $$\text{logit}(p) = \sigma^{-1}(p) = \ln\left( \frac{p}{1 - p} \right), \qquad p \in (0, 1)$$
\end{itemize}

\section{Common Pitfalls, Traps \& Misconceptions}

\begin{trapbox}{Trap 1: The Non-Commutativity of Function Composition}
Students routinely assume that function composition behaves like multiplication and commutes: $(f \circ g)(x) \stackrel{?}{=} (g \circ f)(x)$.
\begin{itemize}
    \item In general, $f(g(x)) \neq g(f(x))$.
    \item \textbf{Example:} Let $f(x) = x^2$ and $g(x) = 2x + 1$.
    \begin{align*}
        (f \circ g)(x) &= f(2x + 1) = (2x + 1)^2 = 4x^2 + 4x + 1 \\
        (g \circ f)(x) &= g(x^2) = 2(x^2) + 1 = 2x^2 + 1
    \end{align*}
    Clearly $4x^2 + 4x + 1 \neq 2x^2 + 1$. Order is paramount in deep neural network layers!
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 2: The Composite Function Domain Fallacy}
A classic exam trap is determining the domain of $f(g(x))$ by looking \textit{only} at the simplified final formula.
\begin{itemize}
    \item \textbf{Example:} Let $g(x) = \sqrt{x}$ (domain: $[0, \infty)$) and $f(u) = u^2$ (domain: $\R$).
    \item The composite formula is $(f \circ g)(x) = (\sqrt{x})^2 = x$.
    \item \textbf{Incorrect:} Looking at $y = x$, a student claims the domain is all real numbers $\R$.
    \item \textbf{Correct:} By definition, $\text{Dom}(f \circ g) = \{x \in \text{Dom}(g) \mid g(x) \in \text{Dom}(f)\}$. The input $x = -4$ cannot even enter the inner function $g(x)$! The true domain is strictly $[0, \infty)$.
\end{itemize}
\end{trapbox}

\begin{trapbox}{Trap 3: Inverting Compositions: The Socks-and-Shoes Reversal Trap}
When inverting a composite function, the order of the inverse operations must be reversed:
$$(f \circ g)^{-1} = g^{-1} \circ f^{-1} \quad \left(\textbf{NOT } f^{-1} \circ g^{-1}\right)$$
\textbf{Intuition:} If you put on your socks ($g$) and then put on your shoes ($f$), to undo this process you must first take off your shoes ($f^{-1}$) and then take off your socks ($g^{-1}$).
\end{trapbox}

\begin{trapbox}{Trap 4: Sigmoid Saturation and the Vanishing Gradient Trap}
The derivative of the sigmoid activation function satisfies:
$$\sigma'(z) = \sigma(z)(1 - \sigma(z))$$
\begin{itemize}
    \item Notice that when $|z|$ is large (e.g., $z = 6$ or $z = -6$), $\sigma(z) \approx 1$ or $\sigma(z) \approx 0$.
    \item In both saturated regimes, the derivative collapses: $\sigma'(z) \approx 0 \times 1 = 0$.
    \item In deep networks, multiplying these near-zero derivatives across multiple composite layers causes the \textbf{vanishing gradient problem}, freezing neural weight updates. This is why modern deep architectures favor the \textbf{ReLU} activation ($R(x) = \max(0, x)$).
\end{itemize}
\end{trapbox}

\section{Python Implementation: Neural Feedforward Passes and Logit Inversion}

\begin{lstlisting}[caption={Function Compositions, Sigmoid, and Logit Inversion in Python}]
import numpy as np
import sympy as sp

# 1. Neural Network Feedforward Pass as Function Composition
# Architecture: Input x -> Linear Layer L(x) -> ReLU Activation R(z) -> Sigmoid Prob S(a)
def linear_layer(x, w=1.5, b=-2.0):
    return w * x + b

def relu_activation(z):
    return np.maximum(0.0, z)

def sigmoid_activation(a):
    return 1.0 / (1.0 + np.exp(-a))

# Composite forward pass: y_pred = (Sigmoid o ReLU o Linear)(x)
inputs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0])
z_linear = linear_layer(inputs)
a_relu = relu_activation(z_linear)
probs = sigmoid_activation(a_relu)

print("Composite Neural Layer Evaluation:")
for x_in, z, a, p in zip(inputs, z_linear, a_relu, probs):
    print(f"  x = {x_in:4.1f} -> Linear = {z:5.2f} -> ReLU = {a:4.2f} -> Sigmoid Prob = {p:.4f}")

# 2. Symbolic Inversion and Logit Function Verification with SymPy
p_sym = sp.symbols('p', real=True, positive=True)
logit_expr = sp.log(p_sym / (1 - p_sym))

# Test for p = 0.8808 (from x=3.0 above, where a=2.5)
p_val = 1.0 / (1.0 + np.exp(-2.5))  # ~0.92414
recovered_z = float(logit_expr.subs(p_sym, p_val))
print(f"\nLogit Inversion Verification:")
print(f"  Probability p = {p_val:.5f} -> Recovered Score z = {recovered_z:.4f} (Matches 2.50!)")

# 3. Verifying Inversion of Composite Functions: (f o g)^(-1) = g^(-1) o f^(-1)
# Let f(x) = 2x + 3  -> f^(-1)(y) = (y - 3)/2
# Let g(x) = x - 5   -> g^(-1)(y) = y + 5
# (f o g)(x) = 2(x - 5) + 3 = 2x - 7 -> (f o g)^(-1)(y) = (y + 7)/2
# g^(-1)(f^(-1)(y)) = ((y - 3)/2) + 5 = (y - 3 + 10)/2 = (y + 7)/2. Identical!
print("\nReversal Property (Socks and Shoes) analytically verified.")
\end{lstlisting}

\subsection*{Part A: Computational and Analytical Problems}

\begin{enumerate}
    \item \textbf{Composite Function Formulations and Restricted Domains:} Consider functions:
    $$f(x) = \sqrt{2x - 6}, \qquad g(x) = \frac{x + 2}{x - 3}$$
    \begin{enumerate}
        \item State the natural domains of $f(x)$ and $g(x)$ in interval notation.
        \item Formulate the composite expression $(f \circ g)(x)$ in simplified algebraic form.
        \item Rigorously determine the exact domain of $(f \circ g)(x)$ using the formal definition $\text{Dom}(f \circ g) = \{x \in \text{Dom}(g) \mid g(x) \in \text{Dom}(f)\}$.
        \item Formulate $(g \circ f)(x)$ and compute its domain.
    \end{enumerate}

    \item \textbf{Analytical Inversion of Rational Mappings:} Consider the function:
    $$\func{f}{\R \setminus \{2\}}{\R \setminus \{4\}}, \qquad f(x) = \frac{4x + 1}{x - 2}$$
    \begin{enumerate}
        \item Prove that $f$ is strictly injective.
        \item Derive the explicit algebraic formula for the inverse function $f^{-1}(y)$.
        \item Verify through direct algebraic expansion that $(f \circ f^{-1})(y) = y$ and $(f^{-1} \circ f)(x) = x$.
    \end{enumerate}

    \item \textbf{The Sigmoid Function and Logit Probability Link:} In logistic classification:
    $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
    \begin{enumerate}
        \item Prove the fundamental reflection identity: $\sigma(-z) = 1 - \sigma(z)$ for all $z \in \R$.
        \item If a logistic regression model outputs score $z = 2.0$, compute the predicted probability $p = \sigma(2.0)$ (use $e^2 \approx 7.389$).
        \item Given an observed event probability $p = 0.80$, compute the exact analytical log-odds (logit score) $z = \text{logit}(0.80) = \ln\left(\frac{0.80}{0.20}\right)$.
    \end{enumerate}

    \item \textbf{Neural Layer Activation Pipelines:} A data pipeline models a single neuron with input feature $x$:
    \begin{itemize}
        \item Affine transformation: $z(x) = 2x - 4$
        \item Non-linear activation: $a(z) = \max(0, z)$ (ReLU)
        \item Probabilistic readout: $p(a) = \frac{1}{1 + e^{-a}}$ (Sigmoid)
    \end{itemize}
    \begin{enumerate}
        \item Express the complete forward pipeline as a single composite function $P(x) = (p \circ a \circ z)(x)$.
        \item Evaluate $P(1.0)$, $P(2.0)$, and $P(5.0)$.
        \item Explain what happens to the output probability for any input $x \le 2.0$.
    \end{enumerate}

    \item \textbf{Reversal Property of Composite Inverses:} Let $f(x) = 3x - 5$ and $g(x) = \frac{x + 4}{2}$.
    \begin{enumerate}
        \item Compute the composite function $h(x) = (f \circ g)(x)$.
        \item Find the inverse $h^{-1}(x)$ directly from $h(x)$.
        \item Compute the individual inverses $f^{-1}(x)$ and $g^{-1}(x)$.
        \item Formulate the composition $(g^{-1} \circ f^{-1})(x)$ and show that it matches $h^{-1}(x)$ identically, demonstrating the socks-and-shoes reversal law.
    \end{enumerate}
\end{enumerate}

\subsection*{Part B: Conceptual and Diagnostic Multiple Choice Questions}

\begin{enumerate}[resume]
\item \textbf{Conceptual Diagnostic: Composite Domain Fallacy} \\
Let $f(x) = \sqrt{x}$ and $g(x) = x^2 - 9$. An engineering student formulates $(f \circ g)(x) = \sqrt{x^2 - 9}$ and concludes that the domain is $(-\infty, \infty)$ because \textit{"$x^2$ is always non-negative."} What is the \textbf{correct mathematical domain} of $(f \circ g)(x)$?
\begin{enumerate}
    \item $(-\infty, \infty)$ because the square of any real number is non-negative.
    \item $[0, \infty)$ because the square root function requires non-negative inputs.
    \item $(-\infty, -3] \cup [3, \infty)$ because the radicand $g(x) = x^2 - 9$ must satisfy $x^2 - 9 \ge 0$.
    \item $[-3, 3]$ because the function is bounded between the two roots.
\end{enumerate}

\item \textbf{Conceptual Diagnostic: Reversal Law of Inversion} \\
In deep learning, an autoencoder encoder network maps input data $\mathbf{x}$ to latent space through two successive bijective layer transformations: $\mathbf{z} = f_2(f_1(\mathbf{x}))$. Which mathematical formula correctly defines the exact decoder network that recovers $\mathbf{x}$?
\begin{enumerate}
    \item $\mathbf{x} = (f_1^{-1} \circ f_2^{-1})(\mathbf{z})$
    \item $\mathbf{x} = (f_2^{-1} \circ f_1^{-1})(\mathbf{z})$
    \item $\mathbf{x} = (f_1 \circ f_2)^{-1}(\mathbf{z}) = (f_1^{-1} \circ f_2^{-1})(\mathbf{z})$
    \item $\mathbf{x} = (f_2 \circ f_1)(\mathbf{z})$
\end{enumerate}
\end{enumerate}
