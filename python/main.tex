\chapter*{Introduction}
\addcontentsline{toc}{chapter}{Introduction}

Welcome to the \textbf{Programming in Python} Comprehensive Textbook for the IIT Madras BS Degree Programme. This textbook is designed to build software engineering and computational thinking skills from ground-level Python fundamentals through to scientific computing with NumPy, Pandas, and Matplotlib.

\section*{Structure of this Guide}
The course is organized into \textbf{12 Chapters}:
\begin{itemize}
    \item \textbf{Chapters 1--4 (Quiz 1 Content):} Variables, Data Types, Control Flow, Loops, Lists, and Basic Algorithmic Logic.
    \item \textbf{Chapters 5--8 (Quiz 2 Content):} Data Structures (Tuples, Dictionaries, Sets), Functions, Functional Programming, Comprehensions, File Handling, and Exception Management.
    \item \textbf{Chapters 9--12 (End-Term Content):} Recursion, Searching Algorithms, Object-Oriented Programming (OOP), NumPy, Pandas, and Data Visualization.
\end{itemize}
