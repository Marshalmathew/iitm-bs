\chapter*{Introduction}
\addcontentsline{toc}{chapter}{Introduction}

Welcome to \textbf{Mathematics for Data Science 2 (MDS2)}. Linear algebra and multivariable calculus form the core mathematical foundation for machine learning algorithms, deep learning neural networks, optimization routines, and dimensionality reduction techniques like SVD and PCA.

\section*{Structure of this Guide}
The course is divided into \textbf{12 Chapters}:
\begin{itemize}
    \item \textbf{Chapters 1--4 (Quiz 1 Content):} Vector Spaces, Matrix Algebra, Systems of Linear Equations, Gaussian Elimination, Subspaces, Basis, and Dimension.
    \item \textbf{Chapters 5--8 (Quiz 2 Content):} Null Space, Linear Transformations, Rank-Nullity Theorem, Inner Product Spaces, Gram-Schmidt Orthogonalization, and Projections.
    \item \textbf{Chapters 9--12 (End-Term Content):} Multivariable Differential Calculus, Gradients, Tangent Planes, Hessian Matrices, Steepest Descent, Eigenvalues, Eigenvectors, Diagonalization, and Singular Value Decomposition (SVD).
\end{itemize}
